# SQL Coursework – Relational Database Design & Querying

## Overview
This coursework demonstrates the design and querying of a **relational database** using SQL. The project focuses on applying core database principles—schema design, normalisation, and analytical querying—to store, retrieve, and analyse structured data accurately and efficiently.

The database was implemented and tested using **SQLite**, with an emphasis on correctness, clarity, and maintainability.

---

## Objectives
- Design a relational database schema that models a real-world scenario.
- Apply **normalisation principles** to reduce redundancy and maintain data integrity.
- Write SQL queries to extract meaningful insights from structured data.
- Demonstrate understanding of relationships, constraints, and joins.

---

## Database Design
- Tables represent distinct entities with clearly defined responsibilities.
- **Primary keys** uniquely identify records in each table.
- **Foreign keys** enforce referential integrity between related tables.
- The schema follows **Third Normal Form (3NF)** to minimise duplication and prevent anomalies.

An entity–relationship (ER) diagram was used during the design phase to visualise table structures and relationships.

---

## Key Features
- Relational schema with well-defined entity relationships.
- Use of `JOIN` operations to combine data across multiple tables.
- Analytical queries using `GROUP BY`, `HAVING`, and aggregate functions.
- Constraints to ensure data validity and consistency.
